# gl4es test traces

The recorded GL traces that gl4es's own tests replay (`tests/test.sh`, `tests/tests.sh`) are not kept in this fork:
they are compressed archives, used by none of JKXR's builds, and a repository listed in the AVP Ports Index carries
no archives. They are in the gl4es repository itself: <https://github.com/ptitSeb/gl4es/tree/master/traces>.
